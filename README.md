# lattuada-workspace-cloud

Mirror scoped, di sola sincronizzazione, del workspace di Alberto Lattuada — **non è la fonte primaria**, che resta il Mac locale.

Serve solo perché le routine cloud (VERA, OTTO) possano leggere i contenuti editoriali senza dipendere dal Mac acceso.

Aggiornato da `automations/sync-cloud-repo.sh` (locale, non da modificare qui direttamente: le modifiche verrebbero sovrascritte al prossimo sync).

Contenuto: `03-giornalismo/` (esclusi gli archivi storici di PIERO), `04-linkedin/*.md` (no grafiche), `06-lasvegas/collaborazioni/task-list.md`, `automations/` (script e roster di riferimento).
