## Testo

Signing in a new regulated market fixes your catalogue for exactly one day.

From day two, the number that matters is how fast new games reach that market.

In Italy every new title goes down the same path as the first ones: an accredited lab, the concessionaire's approval, integration with the central system, authorisation for the .it market. In Germany every new virtual slot needs its own approval before an operator can offer it. None of this stops after launch. It repeats with every release, for as long as the contract runs.

The unlicensed sites your players also see don't wait for any of those steps.

That gap is where the work after signing actually sits. The integration ends at some point. The release pipeline never does.

Three things worth agreeing before the first new release reaches you, not after:

1. Who submits each new game for certification or approval, and who pays for it.
2. Which studios release versions built for that market, and which only adapt global ones.
3. How many weeks pass between a global launch and availability in your market. Measured, not promised.

If you only negotiated the catalogue you launch with, you negotiated the smallest part of the deal.
